# Independent Bookstore Events Page

A responsive digital events page for an independent bookstore, built as part of the Prodesk IT internship assignment.

## Features

- Responsive design for desktop, tablet, and mobile
- Upcoming events display
- Event search functionality
- Add new event functionality
- Form validation for invalid and missing inputs
- Empty-state handling for unsuccessful searches
- Loading indicator during search operations
- Input sanitization for security
- Accessibility features including ARIA labels
- Simulated analytics logging

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## Project

This project was developed as part of the Prodesk IT internship assignment.
